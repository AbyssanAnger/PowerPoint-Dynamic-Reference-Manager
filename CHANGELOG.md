## [1.0.0] - 2026-01-02

### Added

- Automatic citation numbering from BibTeX files
- Dynamic bibliography generation
- Custom ribbon tab "Dynamic References"
- Support for citation keys with special characters
- Detection of citations within grouped shapes
- Spatial sorting of citations (top-left to bottom-right)
- Citation history persistence using presentation tags
- Reset citations functionality
- GitHub and PayPal donation links in ribbon
- Support for URL and Note fields in BibTeX entries
- Graceful handling of missing BibTeX fields

### Features

- BibTeX file selection dialog
- Automatic bibliography slide generation
- Citation format: `[Key]` → `[1]`, `[2]`, etc.
- Compatible with Zotero, Citavi, and Mendeley exports
