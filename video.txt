In the following I will show you how you can insert the Add-In into your PowerPoint and how to use it.

# short video showing the installation process
1. Download the Dynamic_Reference_Manager.ppam file and extract it. This is a PowerPoint Add-In file that you can install into PowerPoint.
2. Open PowerPoint and go to File > Options > Add-Ins.
3. Click on "PowerPoint Add-ins" in the Manage dropdown and click "Go".
4. Click on "Add" and select the Dynamic_Reference_Manager.ppam file.
5. Click "OK" to close the dialog.
6. Click "OK" again to close the Add-Ins dialog.
7. Restart PowerPoint.

Now the add will show up in the ribbon every time you open PowerPoint.

# short video showing the usage process

Here is how it works:

1. Load your .bib file
2. Insert citations in your PowerPoint slides using the format [Key], where Key corresponds to the citation key in your BibTeX file
3. Run the macro
4. The macro will replace all citations with numbers and create a bibliography slide

# short video showing the tool in action

This Add in isn't finished yet by far and has some limitations:

1. It only works with .bib files
2. It can only handle citations in the format [Key]
3. It can only handle one bibliography per presentation
4. It can only create the bibliography in the style: author, year, title

That is why I am open to suggestions and contributions. I uploaded the source code to GitHub and I would be happy to hear from you if you have any suggestions or if you want to contribute to the project.
